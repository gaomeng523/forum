二分查找最坑的不是思路，是边界。记住一个原则：
while 里用 left < right 还是 left <= right，取决于你的 right 是开区间还是闭区间。

开区间 [left, right) → while (left < right)，right = mid
闭区间 [left, right] → while (left <= right)，right = mid - 1
